## Objective

**DNS** means **D**omain **N**ame **S**ystem and is a set of elements (DNS servers, DNS zones, etc.) that map a domain name to an IP address.

For further explanation, please refer to our guides “[Everything you need to know about DNS servers](/guides/web-cloud/domains/dns-server-general-information)” and “[Everything you need to know about DNS zone](/guides/web-cloud/domains/dns-zone-general-information)”

**This guide explains how to edit your OVHcloud DNS zone via the OVHcloud Control Panel.**

## Requirements

- OVHcloud DNS servers in use for the domain name concerned

:::warning
- If your domain name does not use OVHcloud DNS servers, you will need to edit the configuration using the interface of your service provider that manages your domain name.

- If your domain name is registered with OVHcloud, you can check if it uses our configuration. If needed, refer to our guide on [Modifying the DNS servers for an OVHcloud domain name](/guides/web-cloud/domains/dns-server-edit).

In both of the above cases, be careful when making your DNS server changes. The old configuration that can be applied to your domain name will no longer be active if you have not previously reconfigured and customised the new DNS zone present at OVHcloud.
You can only have one active DNS zone per domain name at a time.

:::

## Instructions

:::info
The screenshots in this guide reflect the previous version of the interface and are being updated to the new DNS zone experience. The steps and button names below are up to date.

:::

### Access the area for managing an OVHcloud DNS zone

:::info
Unlike domain names, a DNS zone has no "holder", but is managed at OVHcloud through the contact management. If you wish to assign the management of your DNS zone to another OVHcloud customer account, follow our guide [Managing contacts for your services](/guides/account-and-service-management/account-information/managing-contacts).

:::

In the [OVHcloud Control Panel](/links/manager), open the `Web Cloud` section, click `Domain names`, then select the domain name concerned. Open the **DNS zone** tab.

The **DNS zone** tab lists your records in a table with one row per record, showing the **subdomain**, the record **type**, its **target** and its **TTL**. You can search the table or filter it by record type.

<img className="thumbnail" alt="dnszone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/tab.png" loading="lazy" />

### Edit your domain name’s OVHcloud DNS zone

**Editing a DNS zone is a sensitive procedure**: An inappropriate change could, for example, make your website unavailable, or prevent your email addresses from receiving new emails.

:::tip
Read our guide on [DNS records](/guides/web-cloud/domains/dns-zone-records) to get a better understanding of your DNS changes.

See also our guide to [subdomains](/guides/web-cloud/domains/domain-create-subdomains) for more information on this topic.

:::

From the **DNS zone** tab you can add, edit or delete a record directly in the table, edit the whole zone in text mode, reset the zone, or view its history. **Click on the headings below to see the details.**

<details>

<summary>Add a new DNS record</summary>

Above the table, click <code className="action">Add an entry</code>. A form opens between the toolbar and the table:

1. Select the **type of DNS field** you want to create (A, AAAA, CNAME, MX, TXT, SPF, DKIM, DMARC, CAA, SRV, TLSA, HTTPS, etc.). Each type shows a short description of its purpose.
2. Fill in the fields for that record type (subdomain, target, and any type-specific fields).
3. Set the **TTL** — leave it on `By default` or choose `Customised` to enter a value.
4. Confirm to add the record.

We recommend that you first check whether this record already exists and points to a different target. To do this, use the search field or filter the table by record type. If the record exists, edit it instead (see below).

> When the target of your record is a URL, remember to punctuate it. If you do not do this, your domain name will be automatically added to the end of your target.
> **Example**: You want to create a CNAME record from `test.mydomain.ovh` to `mydomain.ovh`.
> You must then have as target `mydomain.ovh.` and not `mydomain.ovh` without the **.** at the end.

</details>

<details>

<summary>Modify an existing DNS record</summary>

In the table, on the row of the record concerned, open the actions menu <code className="action">⋮</code> and click <code className="action">Edit the entry</code>. The row expands into an edit form: change the values, then confirm.

</details>

<details>

<summary>Delete a DNS record</summary>

In the table, on the row of the record concerned, open the actions menu <code className="action">⋮</code> and click <code className="action">Delete the entry</code>, then confirm.

To delete several records at once, tick their checkboxes on the left of the table, then click the <code className="action">Delete</code> button that appears above the table.

</details>

<details>

<summary>Edit the zone in text mode</summary>

:::warning
For informed users only. Be careful with syntax when you make changes.

:::

Above the table, open the <code className="action">Actions on my zone</code> menu and click <code className="action">Edit in text mode</code>, then follow the steps that appear.

:::warning
Do not modify the DNS records of your DNS zone in favour of DNS servers external to OVHcloud in text mode. This DNS zone works **only** with OVHcloud DNS servers.

:::

</details>

<details>

<summary>Reset the DNS zone</summary>

By resetting your DNS zone, you can revert back to a minimal configuration, with OVHcloud default records, or your services’ records. You can also point your domain name to custom web hosting and email services.

:::danger
Before you reset your DNS zone, ensure that your domain name is not attached to services that are in use, such as a website or email addresses.

:::

Above the table, open the <code className="action">Actions on my zone</code> menu and click <code className="action">Reset my DNS zone</code>, then follow the steps in the panel that opens:

- Choose whether to reset with the **minimum records**. Defining minimal records in a DNS zone prevents error responses when the domain name is queried.
- Set the target for the **web hosting** IP address (`A` record): OVHcloud `Redirection`, `OVHcloud web hosting`, or a `Custom` IPv4 address.
- Set the target for the **mail server** (`MX` record): OVHcloud `Redirection`, `OVHcloud email server`, or a `Custom` server and priority.

</details>

<details>

<summary>View the history of your DNS zone</summary>

Above the table, open the <code className="action">Actions on my zone</code> menu and click <code className="action">View the history of my DNS zone</code>. From there you can view, download and restore a previous version of your zone. For more details, see our guide on [managing the history of a DNS zone](/guides/web-cloud/domains/dns-zone-history).

</details>

### Propagation time

Once you have modified your domain name’s DNS zone, you will need to allow a maximum of 24 hours for the changes to propagate fully, and be effective.

If you would like to reduce this delay for the next edits of your OVHcloud DNS zone, you can adjust the TTL (*Time To Live*), which will apply to all of the records in the DNS zone. To do so, open the <code className="action">Actions on my zone</code> menu above the table and click <code className="action">Edit the default TTL</code>.

You can also modify the TTL of an individual record when adding or editing it.
