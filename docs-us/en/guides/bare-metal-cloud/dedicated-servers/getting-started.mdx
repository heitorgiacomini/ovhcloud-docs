# Getting started with a dedicated server

This guide explains how to order and perform the initial configuration of an
OVHcloud US dedicated server.

## Steps

1. Choose a server range that matches your workload.
2. Complete the order in the OVHcloud US Control Panel.
3. Install your operating system from the available templates.
4. Connect over SSH to finish your setup.
