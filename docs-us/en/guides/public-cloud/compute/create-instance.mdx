# Creating a Public Cloud instance

This guide walks you through creating a Public Cloud instance in the OVHcloud US
Control Panel.

## Prerequisites

- An active OVHcloud US account
- A Public Cloud project

## Steps

1. Open the Public Cloud section of the Control Panel.
2. Select **Instances**, then **Create an instance**.
3. Choose a region, flavor, and image.
4. Confirm to launch the instance.
